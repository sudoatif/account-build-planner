# More Builds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Mithril gloves, Adamant gloves, Song of the Elves and Quest cape builds to the picker.

**Architecture:** Gloves builds are the Barrows route trimmed to the prerequisite closure of their target subquests (`Build.needed`). SOTE and Quest cape come from a generated `QuestData.optimalOrder()` (wiki data), staged by quest point bands (`Build.byQp`). The Planner only reports a QP target for builds that use filler quests.

**Tech Stack:** Java 11, RuneLite 1.13.6 API, JUnit 4; Node 18+ for the generator.

**Spec:** `docs/superpowers/specs/2026-11-18-more-builds-design.md`

## Global Constraints

- Build order and names: `MITHRIL_GLOVES("Mithril gloves", ItemID.HUNDRED_GAUNTLETS_LEVEL_6)`, `ADAMANT_GLOVES("Adamant gloves", ItemID.HUNDRED_GAUNTLETS_LEVEL_7)`, `BARROWS_GLOVES` (unchanged), `SOTE("Song of the Elves", ItemID.PRIF_TELEPORT_CRYSTAL)`, `QUEST_CAPE("Quest cape", ItemID.SKILLCAPE_QP)`.
- Mithril targets: RFD Wartface & Bentnoze, Mountain Dwarf, Pirate Pete, Lumbridge Guide, Skrach Uglogwee. Adamant: the same plus Evil Dave.
- QP band stage names: `"0-50 QP"`, `"50-100 QP"`, ... (band = QP before the step / 50).
- Generated file header says it's generated by `tools/quest-data.js` from the OSRS Wiki, dated, not to be hand-edited.
- No commits (user hasn't asked). Restore point: the backup zip.

## Review Focus

1. Quest cape for a player with most quests done: Next tab must pick the first unfinished quest in guide order, not choke on 202 rows. (Manual in-game; Task 3.)
2. Untrackable requirements (Barbarian Firemaking, Combat 85, started X) appear as notes, never as `after` quests that can't be finished. Pinned by Task 2 test `generatedRoutesOnlyNeedTrackableQuests` (every `after` quest is in the same route).
3. A gloves subset must never contain filler (the planner would skip a needed prereq). Pinned by Task 2 test `glovesBuildsFreeTheRightSubquests`.
4. QP line: someone with 150 QP picking Mithril sees no "150/x QP". Pinned by Task 2 test `qpTargetOnlyForFillerBuilds`.
5. Switching builds after Start: Refresh plans the newly picked build. (Existing behaviour; manual check in Task 3.)

### Task 1: Generator and generated QuestData

**Files:**
- Create: `tools/quest-data.js`
- Create (generated): `src/main/java/com/buildplanner/QuestData.java`

**Interfaces:**
- Produces: `static List<Step> QuestData.optimalOrder()`: fresh `Step` instances on every call, built with `Step.q(...)`, `.after(...)`, `.skill(...)`, `.qpReq(...)`, `.note(...)`.

- [ ] **Step 1:** Write `tools/quest-data.js` (no npm deps). It fetches `Module:Questreq/data` and `Optimal quest guide` (raw), dumps RuneLite's `Quest` enum by running `java` on a temp single-file program against the runelite-api jar found under `~/.gradle/caches` (or a path given as an argument), and maps wiki names to constants (with the RFD "Freeing ..." aliases). The route is the guide's rows mapped to quests: those with QP > 0 plus their prerequisite closure, in guide order. Requirements come from the module, falling back to the quest page's `{{Quest details|requirements=}}` for quests missing from it. Ironman-only levels are dropped. `Quest point` becomes `qpReq`; skills not in `Skill` (Combat, Kudos, ...) and untrackable or "started" prerequisites become the note. The last step's note lists guide quests RuneLite lacks. The script fails loudly if any prerequisite is out of order.
- [ ] **Step 2:** Run `node tools/quest-data.js`. Expected: it writes `QuestData.java` and prints `202 steps, 344 QP`, plus the excluded quests (The Birds and the Wasps, A Shell of a Friend).
- [ ] **Step 3:** Run `.\gradlew.bat compileJava`. Expected: BUILD SUCCESSFUL (every constant exists).
